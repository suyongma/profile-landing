# 메인 서비스 카드 · Meshy 소품

2026-10-18 사용자 요청으로 Meshy API를 이용해 네 소품을 생성했다. 형상은 `meshy-7.1` 10,000면 remesh, 재질은 2K PBR이며 투명 미리보기를 요청했다. 각 소품 preview 20 + refine 10, API 응답의 consumed_credits 합계 120크레딧이다.

- tests: 라벤더 퍼즐 큐브
- world: 작은 포털 섬
- mapt: 청록색 미니 로봇
- shopping: 민트 쇼핑백

메인은 3D 뷰어 없이 192×192 투명 WebP를 48px로 표시한다. 기존 32px 화살표 영역 중앙에 이미지를 배치하고 작은 이동 화살표를 유지한다. 번호·문구·링크·카드 폭과 높이·배치는 보존한다. 이미지 4개의 총 크기는 22,620바이트다. 새 자산은 `public/assets/service-cards/*-v1.webp`, 기존 CSS/JS 캐시 버전은 v12로 맞춘다. 공통 shared/와 fonts/는 변경하지 않는다.

3D GLB 원본과 512px 투명 미리보기·생성 프롬프트/작업 ID는 추적하지 않는 `output/meshy-cards/`에 보관한다. 원본 GLB는 서비스에 업로드하지 않는다. API 응답과 서명된 다운로드 URL은 `.local-recovery/meshy-cards/`에만 남기며 API 키는 원래 사용자 설정 파일에서 실행 시 읽는다. 키를 소스·자산·문서에 저장하지 않는다.

검증: 320/390/1440px × light/dark 6조합에서 기존 카드의 x/y/폭/높이·링크와 동일하고 가로 넘침, 이미지-본문 겹침 및 JavaScript 오류가 없는지 확인한다. 모든 이미지가 정상 로드되는지 확인하며 최종 스크린샷은 `output/meshy-cards/`에 둔다.

이 작업은 로컬 검토 적용이며 운영 배포 승인은 아직 요청되지 않았다. main 푸시는 자동 운영 배포를 일으킬 수 있으므로 미리보기 검토 단계에서는 하지 않는다.
