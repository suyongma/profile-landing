적용 범위

이 문서는 마숑(MASHONG)의 iOS 앱 새싹포켓, 광고그거, TowerMates, Mashong을 대상으로 합니다. 앱별로 이용하는 기능과 처리 정보가 다릅니다. 외부 웹 서비스로 이동하는 경우 해당 서비스의 개인정보 안내도 함께 확인해야 합니다. 출시된 앱의 동작을 기준으로 적용하며, 아직 배포되지 않은 기능은 별도로 구분합니다.

새싹포켓

앱 식별자: com.suyongma.sproutpocket. 가상 펫 육성 게임으로, 회원가입이나 로그인 기능은 확인되지 않았습니다. 펫 상태, 도감, 소리·알림 설정과 광고 제거 상태를 기기에 저장합니다. 돌봄 알림은 기기 안에서 예약하는 로컬 알림입니다.

하단 배너 광고에 Google AdMob을 사용합니다. 광고 SDK는 기기 식별자, IP 주소, 기기·OS 정보, IP 기반 대략적 위치, 광고 노출·클릭 및 진단 정보를 처리할 수 있습니다. 이는 위치 권한으로 GPS를 조회하는 것과 다릅니다. 광고 제거 구매가 확인되면 이후 광고 요청을 하지 않는 구현입니다.

광고 제거는 Apple 앱 내 구입으로 처리합니다. 개발자 서버로 구매 영수증을 전송하는 코드는 확인되지 않았습니다. 현재 조사한 구현에는 ATT 요청 및 UMP 동의 화면이 없습니다. 이를 추적이나 데이터 전송이 전혀 없다는 뜻으로 해석할 수는 없습니다.

광고그거

앱 식별자: com.suyongma.g1tower. 게임 진행, 설정, 해금 기록, 광고 제거 상태 등을 기기에 저장합니다. 회원가입·로그인·개발자 서버 통신은 확인되지 않았습니다.

Google AdMob 전면광고를 사용하며, iOS 추적 허용 요청에 응답한 후 광고 SDK를 초기화합니다. 추적을 거부해도 광고 SDK가 동작할 수 있습니다. 거부가 모든 데이터 전송의 중단이나 비맞춤형 광고 설정의 확정을 뜻하지는 않습니다. SDK의 처리 항목에는 기기 식별자, IP 기반 대략적 위치, 광고·상호작용·진단 정보가 포함될 수 있습니다.

광고 제거 비소모성 구매와 복원 코드가 있으나, 조사 시점에는 스토어 상품이 등록되지 않아 구매 기능은 미출시입니다. 구매 기능이 출시되면 적용 내역을 갱신합니다.

TowerMates

앱 식별자: com.suyongma.towermates. 개발 단계의 협동 타워 디펜스 게임입니다. 앱이 생성한 설치 ID, 닉네임, 계정 식별자와 세션·재접속 정보를 인증·방 참가·게임 연결에 사용합니다. 개발용 인증은 이메일·비밀번호 로그인과 구분됩니다.

설치 ID·닉네임·인증정보를 개발자 서버로 전송하며, 닉네임은 같은 방 참가자에게 표시되고 서버 로그에도 남을 수 있습니다. 현재 닉네임 기본값에 기기 이름을 사용하는 경로가 있습니다. 전투 서버는 접속 IP와 게임 명령을 처리합니다. 인증 DB는 개발 로컬 D1, 전투 서버는 개발자 NAS를 사용하는 것으로 보고됐으며 출시 서버 구성은 미확정입니다.

Google AdMob 전면광고와 Apple의 광고 제거 구매·복원 기능이 구현되어 있습니다. 현재 ATT·UMP 화면은 확인되지 않았습니다. 계정·서버 데이터 삭제 기능과 보관 기간은 확정되지 않았으므로 앱 제거만으로 서버 데이터까지 삭제된다고 안내할 수 없습니다.

Mashong

앱 식별자: com.mashong.worldapp. 조사 자료의 배포 기록은 TestFlight 0.4.0(7)입니다. 중앙 마숑 계정으로 인증하고 회원 식별정보, 인증·복구 정보, 기기 세션 정보를 처리합니다. 선택한 소셜 로그인 제공자는 인증 과정에서 해당 계정 정보를 처리합니다.

성향검사 답변과 결과는 사용자가 저장을 선택하면 회원별 서버 저장소에 전송됩니다. 홈 설정·즐겨찾기 등은 기기와 서버에서 처리하며, 인증정보 일부는 iOS Keychain, 비회원 설정과 동기화 대기열 일부는 localStorage에 저장합니다. 결과 이미지 공유는 사용자가 선택한 앱으로 이미지를 전달합니다.

쿠팡 광고·제휴 링크를 사용합니다. 배너를 선택하면 앱 내 격리 광고뷰에서 쿠팡 스크립트가 실행되는 구조입니다. 광고에 회원 ID·인증정보·검사 답변을 직접 전달하는 코드는 확인되지 않았으나, 쿠팡 측 네트워크·쿠키·측정 처리는 별도 확인이 필요합니다.

현재 소스에 위치·날씨와 쇼핑 내장 기능이 추가되어 있지만 7번 빌드에는 포함되지 않았습니다. 위치 좌표의 날씨 서버 전송, Apple WeatherKit 연결 등은 출시 버전과 운영 경로 확인 후 공개 방침에 반영합니다. APNs·FCM 푸시와 전체 삭제 기능도 현재 비활성 상태입니다. 마PT 등 연결된 웹 서비스의 대화·첨부 처리는 별도 조사 대상입니다.

저장과 삭제

현재 확인된 처리 현황

새싹포켓·광고그거의 기기 저장 데이터는 일반적으로 앱 삭제 시 앱 영역과 함께 삭제되지만, 기기·iCloud 백업 사본은 별도입니다. 구매 권리는 Apple 계정의 거래 기록과 관련되며 기기 데이터 삭제와 동일하지 않습니다.

TowerMates·Mashong의 서버 회원정보·검사 기록·세션·로그는 앱 삭제나 로그아웃만으로 모두 지워지지 않습니다. 세션 만료 기간을 개인정보의 보관 기간으로 안내하지 않습니다. Mashong Keychain·공유 캐시·동기화 대기열도 저장 방식별로 구분합니다.

현재 TowerMates·Mashong의 서버 삭제 기능, 항목별 실제 보관기간과 백업 만료 설정은 확정·검증되지 않았습니다. 앱에서 전체 삭제를 요청하는 기능은 제공 여부가 확인되지 않았거나 비활성 상태입니다. 삭제 관련 문의는 아래 이메일로 접수하며 처리 가능한 범위와 절차를 확인하여 안내합니다.

적용 예정인 보관·삭제 기준

아래는 앞으로 구현·검증할 운영 목표입니다. 법적으로 정해진 일괄 최대기간을 뜻하지 않으며, 현재 자동 정리·삭제·백업 만료가 아래 기준대로 동작한다는 뜻도 아닙니다. 실제 적용 시점은 구현·검증 후 이 페이지에 안내합니다.

  • 계정·닉네임·회원 설정: 회원 이용 기간 동안 보관하고, 탈퇴 시 법정 보관 대상 외에는 지체 없이 삭제합니다.
  • 검사 답변·결과 및 서버 게임 기록: 이용 기간 동안 보관하며, 개별 삭제 요청 또는 탈퇴 시 지체 없이 삭제합니다.
  • 인증 세션: 서비스별 유효기간 동안 사용하고, 만료·폐기된 인증정보는 지체 없이 정리합니다. 세션 만료를 다른 개인정보의 삭제 시점으로 보지 않습니다.
  • 일반 장애·진단 로그: 생성일부터 최대 30일 보관합니다. 법적 보관 의무가 별도로 적용되는 보안 감사 기록은 이 항목과 분리해 확정합니다.
  • 일반 고객 문의: 처리 완료일부터 최대 90일 보관합니다. 법정 보존 대상인 소비자 분쟁 기록 등은 구분합니다.
  • 복구용 백업: 해당 데이터가 운영 DB에서 삭제된 날부터 최대 30일 이내 만료·삭제하도록 구성합니다. 접근을 제한하고 복구 목적으로만 사용하며, 복원 시 삭제 대상이 다시 서비스되지 않도록 재삭제 절차를 적용해야 합니다.
  • 개인정보 정정·삭제 요청: 접수일부터 10일 이내 조치 결과 또는 법적 거절 사유와 이의제기 방법 등을 통지하는 절차를 마련합니다. 백업까지 모든 사본이 10일 이내 삭제된다는 뜻은 아닙니다.

다른 법령에 따른 보존 대상은 적용 법령·항목·기간을 확인하여 별도로 보관합니다. Google·Apple 등 외부 업체가 독립적으로 처리하는 데이터의 보관 기간을 마숑이 정한 위 기간으로 일괄 약속하지 않습니다. 개인정보 보유 목적이 끝나면 상한까지 기다리지 않고 지체 없이 파기해야 합니다. 기간별 자동 정리, 백업 만료 및 삭제 요청 절차의 실제 구현을 확인한 후 적용 현황을 갱신합니다.
