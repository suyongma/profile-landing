Yeoreum Design Uploader 개인정보처리방침

게시일 2026년 11월 15일

Yeoreum Design(@masy130) 운영자가 개인용 업로더를 운영합니다. 업로더는 YouTube API 서비스의 YouTube Data API를 사용하며, 아래 설명은 이 도구에서 처리하는 정보에 적용됩니다.

조회하는 정보와 이용 목적

운영자가 Google OAuth로 권한을 부여하면 연결된 YouTube 채널의 ID, 이름, 핸들과 최근 업로드의 영상 식별 정보, 업로드 처리 상태 및 공개 상태를 조회합니다. 이 정보로 업로드 대상 채널을 확인하고 중복 발행을 피하며, 승인한 영상의 처리 결과를 확인합니다. 업로더는 Google 계정 비밀번호를 받지 않습니다.

YouTube에 전송하는 정보

운영자가 발행을 승인하면 영상 파일과 제목, 설명, 태그, 공개 범위 및 시청 대상 설정을 YouTube에 전송합니다. Google과 YouTube가 정보를 처리하는 방식은 Google 개인정보처리방침에서 확인할 수 있습니다.

운영자 기기에 저장하는 정보

OAuth 갱신 토큰은 운영자 기기의 접근이 제한된 파일에 보관합니다. 이후 이미 승인된 범위에서 연결을 갱신할 때 사용합니다. 업로드 ID, 공개 링크와 처리 결과는 같은 기기의 발행 기록에 남습니다.

권한 철회, 삭제 요청 및 문의

Google 계정의 연결 관리에서 업로더의 접근 권한을 철회하면 이후 API 연결을 중단할 수 있습니다. 권한을 철회한 뒤에도 운영자 기기에 남아 있는 토큰이나 API 조회 데이터, 관련 발행 기록은 운영자에게 삭제를 요청할 수 있습니다.
